# Logo thương hiệu

Đặt file logo vào thư mục này, đặt tên **đúng mã thương hiệu** bên dưới. Khi build, chữ tên hãng
trên website tự được thay bằng logo (tên hãng vẫn được giữ làm văn bản thay thế cho Google).

| Thương hiệu | Tên file |
| --- | --- |
| INAX | `inax.svg` |
| TOTO | `toto.svg` |
| Viglacera | `viglacera.svg` |
| Caesar | `caesar.svg` |
| Enic | `enic.svg` |
| Tân Á Đại Thành | `tan-a-dai-thanh.svg` |
| Sơn Hà | `son-ha.svg` |
| Hoa Sen | `hoa-sen.svg` |
| Panasonic | `panasonic.svg` |
| Rạng Đông | `rang-dong.svg` |
| Senko | `senko.svg` |
| Sino | `sino.svg` |
| Aqara | `aqara.svg` |
| FPT Smart Home | `fpt-smart-home.svg` |
| Hunonic | `hunonic.svg` |

- Định dạng: `.svg` (tốt nhất), `.webp` hoặc `.png` nền trong suốt. Logo hiển thị cao 28px.
- Chỉ dùng logo do hãng hoặc nhà phân phối cung cấp cho đại lý (bộ nhận diện / marketing kit),
  hoặc khi đã được hãng cho phép. Logo là nhãn hiệu đã đăng ký của chủ sở hữu.
- Thiếu logo nào thì website hiển thị tên hãng dạng chữ như hiện tại.
