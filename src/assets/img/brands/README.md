# Logo thương hiệu

Đặt file logo vào thư mục này, đặt tên **đúng mã thương hiệu** bên dưới. Khi build, chữ tên hãng
trên website tự được thay bằng logo (tên hãng vẫn được giữ làm văn bản thay thế cho Google).

| Thương hiệu | Tên file (đuôi .svg, .webp hoặc .png) |
| --- | --- |
| INAX | `inax` |
| TOTO | `toto` |
| Viglacera | `viglacera` |
| Caesar | `caesar` |
| Enic | `enic` |
| Tân Á Đại Thành | `tan-a-dai-thanh` |
| Sơn Hà | `son-ha` |
| Hoa Sen | `hoa-sen` |
| Panasonic | `panasonic` |
| Rạng Đông | `rang-dong` |
| Senko | `senko` |
| Sino | `sino` |
| Aqara | `aqara` |
| FPT Smart Home | `fpt-smart-home` |
| Hunonic | `hunonic` |

- Định dạng: `.svg` (tốt nhất), `.webp` hoặc `.png` nền trong suốt. Logo hiển thị cao 28px.
- Logo hiện có được lấy từ website chính thức của từng hãng (Panasonic: news.panasonic.com; INAX: lixil.com.vn).
- Nên dùng logo do hãng hoặc nhà phân phối cung cấp cho đại lý (bộ nhận diện / marketing kit),
  hoặc khi đã được hãng cho phép. Logo là nhãn hiệu đã đăng ký của chủ sở hữu.
- Thiếu logo nào thì website hiển thị tên hãng dạng chữ như hiện tại.
